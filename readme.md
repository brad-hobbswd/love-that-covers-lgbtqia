# Love That Covers | LGBTQIA+ Edition
### A Journey Through Faith, Belonging, Healing, and the Love of Jesus

**Love That Covers | LGBTQIA+ Edition** by Bradley Hobbs is an online book experience exploring stories, struggles, faith, belonging, healing, and spiritual reflection. The project invites readers into thoughtful engagement with grace, compassion, dignity, honest conversation, and the enduring love of Jesus.

## Live Website

https://brad-hobbswd.github.io/love-that-covers-lgbtqia/

- Home

- Store
- Closing

## Features

- Page-by-page reading experience
- Responsive layout and mobile navigation
- Resources and prayer content
- Book and author information
- GitHub Pages hosting

## Purpose

The project aims to create space for people who have carried silence, rejection, difficult questions, or spiritual hurt. It encourages readers to consider faith, hope, healing, dignity, and compassion while reflecting on Scripture.

## Technology

This is a static website built with HTML, CSS, and JavaScript and published with GitHub Pages.
